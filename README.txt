WINGSPAN HOLIDAYS — Website starter
=====================================

Files
- index.html: website structure and content
- style.css: responsive styling
- script.js: mobile navigation, destination filters and WhatsApp enquiry form

How to use
1. Extract the ZIP file.
2. Open index.html in a browser to preview the website.
3. To publish it, upload all three files to a static hosting provider (for example, GitHub Pages, Netlify, or your hosting control panel).

Images and fonts
The website uses remote images from Unsplash and fonts from Google Fonts, so an internet connection is needed for those assets to load. Replace the image URLs in index.html and style.css if you have your own photos.
